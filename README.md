One sentence, spoken by a robot at its own wedding: it vows its last percent of battery to its partner, and if it dies mid-vow, its final log entry will read their name — a joke about dying hardware that lands as a real promise.

## Run it

```sh
node main.ts
```

This writes the vow to `(MAKEFUN_OUTPUT_DIR || "/output")/entry.txt` with no trailing newline. Node 22 stdlib only, deterministic, no network.
